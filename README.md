# World News — 23 November 2026

A deterministic newspaper front page that sums up Monday 23 November 2026's
world news in a single 1024×1024 PNG. Built for the make.fun
"Sum up 23 November's world news in one image" bounty.

`main.py` (Python 3.13) writes `/output/entry.png`. No network, no randomness —
two runs produce identical bytes. Fonts (Carlito/Poppins, OFL) are bundled.

## Run
```
python3 main.py
```
